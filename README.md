# 🛡️ Blinmex | Administration Web Dashboard

Plataforma web de administración interna, backoffice y panel de control para la gestión operativa, comercial y de clientes de **Blinmex**.

---

### 🛠️ Arquitectura & Tecnologías

- **Interfaz:** Bootstrap 5.3 / HTML5 / CSS3 / JavaScript (ES6+)
- **Lógica de Integración:** Consumo de la API REST (`blinmex-backend`)
- **Iconos & Componentes:** Boxicons, ApexCharts, Perfect Scrollbar (UI Kit de Sneat)

---

### 📁 Estructura del Proyecto

- `html/`: Vistas y plantillas de navegación (Dashboard, Login, Módulos)
- `assets/`: Hojas de estilo (CSS), imágenes, plugins JS e iconos
- `scss/`: Fuentes de estilos para compilación y personalización de temas

---

### 🚀 Desarrollo Local & Control de Versiones

1. Clonar el repositorio localmente:
   `git clone https://github.com/blinmexdev/blinmex-admin-web.git`
2. Modificar vistas o conectar componentes con la API en PHP.
3. Guardar y subir cambios:
   `git add .`
   `git commit -m "feat: integración de módulo X"`
   `git push origin main`
